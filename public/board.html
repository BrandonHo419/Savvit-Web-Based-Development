Board settings

Private: only you can view this board. Public: other signed-in users can view it. Semi-private: only you and selected viewers can view it. Only you can edit the board. Anonymous browsing is not available.

Changing visibility also affects access to pins originally created here, including references saved on other boards.

Board viewers

Viewer access applies only while visibility is Semi-private. Private stays owner-only; Public remains visible to all signed-in users. Viewer grants are retained when visibility changes.

After granting access, send the viewer this board's URL. No notification is sent.

    Delete this board only when it contains no original pins. Saved references will be removed; their originals remain unchanged.
